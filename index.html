CSCI599 A3 Hermes Test Assistant

A personal assistant demonstration by Jianshu Hou for a dedicated class-only Google account containing fictional data. This project is not an official Google or university service and is not open for public registration.

What the assistant does

  • Reads test Gmail messages and Google Calendar events to prepare briefings and meeting reminders.
  • Suggests study plans around free calendar time.
  • Prepares email drafts and sends an individual message only after the operator reviews and approves it.
  • Delivers notifications to an operator-controlled Discord channel.

Why Google authorization is requested

Gmail read access supplies message context; Gmail send access supports approved messages. Calendar event read access supports reminders and free-time calculations. The app does not request Calendar write access. Google OAuth lets the operator authorize these capabilities without giving the application the Google account password.

Designed for a limited classroom demonstration

The hosted assistant uses authenticated access and a configured account allowlist. Google data is processed in the private assistant deployment and, when model processing is needed, on the operator's local Gemma model. Public, non-sensitive reasoning requests may use a separate cloud model. Private requests are held if local processing is unavailable.

This public website describes the app. It does not provide access to the assistant, store Google credentials, or display account content.
