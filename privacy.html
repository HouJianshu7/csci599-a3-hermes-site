Privacy policy

CSCI599 A3 Hermes Test Assistant · Effective November 15, 2026

Jianshu Hou operates this independent classroom demonstration for a dedicated test account with fictional data. Do not connect personal, university, or other people's accounts.

Data accessed and purpose

  • Gmail: account identity, message identifiers, sender, subject, selected message bodies and previews, unread/starred status, and timestamps support inbox summaries and related meeting context. The app requests gmail.readonly.
  • Email sending: recipients, subject, and body of an operator-approved draft are submitted to Gmail using gmail.send. Each message requires human review and approval.
  • Calendar: event identifiers, titles, descriptions, start/end times, status, and related event fields support reminders, conflict checks, and free-time calculations. The app requests calendar.events.readonly and cannot create or edit calendar events through this grant.
  • Assistant state: conversations, chosen preferences, tasks, drafts, notices, and operational metadata support continuity and the assignment's evaluation.
  • OAuth credentials: access and refresh tokens maintain the authorized connection. The application does not ask for or store the Google account password.

Processing and sharing

The assistant runs in the operator's Google Cloud deployment. Google data used for model-assisted work is routed to the operator's local Gemma model over a private Tailscale connection; these private requests are held if the local model is unavailable. Separate public, non-sensitive reasoning requests may use OpenAI. Scheduled briefings and reminders are generated from account data and can include email previews and event details.

Google provides the Gmail and Calendar APIs and cloud hosting/storage. Discord receives notices and replies delivered to the configured class-only channel. Tailscale provides the private network connection. The operator and authorized course graders may review test data and demonstration evidence. This website, hosted on GitHub Pages, contains only public app information; GitHub may process ordinary website request metadata under its own privacy policy.

Google user data is not sold, used for advertising, or used to train generalized AI models. CSCI599 A3 Hermes Test Assistant's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

Credentials are stored in private local files, Google Secret Manager, and private runtime state. Conversations, drafts, notices, and preferences are stored in the assistant database and private Google Cloud Storage snapshots. Operational logs record routing and job metadata; the audit logger excludes message bodies and credential values. Discord may retain delivered messages. Authenticated application access, account/channel allowlists, scoped Google permissions, and per-message approval limit access and sending.

Retention, revocation, and deletion

Test data and operational evidence are retained for the assignment and grading/regrade period. There is currently no automatic deletion schedule. The operator can manually remove stored assistant data and snapshots after evaluation. Authorized users can request deletion through their existing private course contact with the maintainer; deletion must include runtime state and snapshots, and separately remove Discord messages or copies where applicable. Revoking access does not itself delete previously stored data.

You can revoke the Google authorization at Google Account connections. This prevents further authorized API use once existing access is invalidated. The original Gmail messages and Calendar events remain in your Google account unless you delete them there.

Contact and changes

Contact Jianshu Hou through the existing private course channel for account-specific or deletion requests. General questions can be posted to the public project issue tracker; do not include private information. This page will be updated when data practices change.
